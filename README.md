A beginner-friendly collection of HTML and CSS example pages created for learning and experimenting with web fundamentals such as selectors, forms, layouts, tables, media elements, and more.

This project is ideal for students practicing core web development concepts.

---

## 📌 Project Overview

This repository contains multiple standalone HTML files and CSS examples that demonstrate important web development concepts including:

- HTML structure and semantic elements
- CSS selectors and styling techniques
- Forms and input validation basics
- Tables and lists
- Media elements (images, audio, video)
- Basic layout and responsive design concepts

## 🚀 Quick Start

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Suryaprakashgowda/WEB-TECH.git
```

### 2️⃣ Navigate into the folder

```bash
cd WEB-TECH
```

### 3️⃣ Open in Browser

You can:

- Double-click any `.html` file to open locally
- **OR** Use a local development server (Recommended)

#### Using VS Code Live Server:

1. Open folder in VS Code
2. Install Live Server extension
3. Right-click `index.html` in `Html/` folder
4. Click "Open with Live Server"

## 🚀 Deployment

### Netlify

1. Sign up for a free account at [Netlify](https://netlify.com)
2. Connect your GitHub repository
3. Deploy the `Html/` folder as the publish directory
4. Your site will be live at `https://your-site-name.netlify.app`

### Vercel

1. Sign up for a free account at [Vercel](https://vercel.com)
2. Connect your GitHub repository
3. Set the root directory to `Html/`
4. Deploy
